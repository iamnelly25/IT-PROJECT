Week 1: Foundations – Hardware & Networking Basics (18–22 May)
This week established the baseline infrastructure for the company. The following was completed:

Business Requirements Analysis – Documented company size, departments, workflows, software needs, and operational risks.
Hardware Inventory -Compiled a full list of required equipment (desktops, laptops, servers, networking gear) with quantities, specs, and justifications.
Software Inventory - Mapped out all necessary software per department, including operating systems, productivity suites, and specialized applications.
Network Diagram - Created a visual topology (via Draw.io) showing how internet connectivity flows from the ISP through the router/firewall and switch to all end devices.
Troubleshooting Scenarios- Documented step-by-step fixes for three common IT issues (e.g., printer offline, network connectivity loss, software crash).
All deliverables serve as the foundation for upcoming security hardening and advanced infrastructure work.


Week 2 - Operating Systems & User Access
(25 -29 May)
Designed and documented the full access control and system administration framework for the organisation's infrastructure.
A User & Permissions Matrix was created assigning department-level access across all shared folders using least-privilege principles. A structured Shared Folder hierarchy was built on the central NAS storage separating public, finance, and HR data cleanly. A Command-Line Administration Guide was produced covering key Ubuntu/Linux terminal commands for folder creation, permission setting, and process monitoring. A Software Deployment Plan was designed to push software installations across all 25 machines from a single central point, eliminating the need for manual installs on each device. An IP Addressing Plan was implemented assigning dedicated subnet ranges to servers, user PCs, printers, and wireless devices for clean network segmentation.
All deliverables completed on schedule. The permissions framework and IP structure established this week feed directly into Week 3 network security and monitoring work.

Week 3 - System Administration & Cybersecurity
(1 - 5 June)
Designed and documented the full cybersecurity and business continuity framework to protect the organisation's data, staff, and systems.
A Backup & Disaster Recovery Plan was established scheduling daily automated backups to the on-site NAS at 20:00 and weekly encrypted copies to cloud storage. In the event of a major incident such as fire or ransomware the plan guarantees full system restoration within 24 hours from the cloud backup. A Cybersecurity Policy was written setting the minimum security standards for all staff including mandatory multi-factor authentication, full laptop encryption, 12-character minimum passwords, and active antivirus on every device. A Risk Assessment Matrix was compiled identifying the organisation's key threats, rating each by likelihood and impact, and documenting mitigation steps — phishing and ransomware were identified as the highest priority risks requiring immediate controls. An Incident Response Plan was produced giving IT staff a clear step-by-step playbook for common attack scenarios — ransomware response for example follows a four-step process of isolating the device, alerting the IT lead, restoring from the last clean backup, and reporting to management. A Security Awareness Training Outline was developed as a 30-minute staff session covering how to identify phishing emails, safe password habits, and the correct steps to take after clicking a suspicious link.
All deliverables completed on schedule. The policies and recovery procedures established this week form the security baseline the organisation carries into live operations.

Week 4 -Final Project Report
(8 - 12 June)
All documentation produced across Weeks 1 through 3 was reviewed, refined, and consolidated into a single polished project report.
The Final Project Report brings together the network infrastructure plan from Week 1, the user access control framework and IP addressing scheme from Week 2, and the cybersecurity policies and disaster recovery procedures from Week 3. Each section was reviewed for consistency and clarity before being compiled into one cohesive document. The report presents a complete end-to-end IT infrastructure solution — from physical equipment and network design through to user permissions, system administration, and security protocols — demonstrating how each component connects and supports the others.
The completed report serves as a handover-ready document that any incoming IT administrator or stakeholder could pick up and action immediately.
