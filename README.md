Week 1: Foundations – Hardware & Networking Basics (18–22 May)
This week established the baseline infrastructure for the company. The following was completed:

Business Requirements Analysis – Documented company size, departments, workflows, software needs, and operational risks.
Hardware Inventory -Compiled a full list of required equipment (desktops, laptops, servers, networking gear) with quantities, specs, and justifications.
Software Inventory - Mapped out all necessary software per department, including operating systems, productivity suites, and specialized applications.
Network Diagram - Created a visual topology (via Draw.io) showing how internet connectivity flows from the ISP through the router/firewall and switch to all end devices.
Troubleshooting Scenarios- Documented step-by-step fixes for three common IT issues (e.g., printer offline, network connectivity loss, software crash).
All deliverables serve as the foundation for upcoming security hardening and advanced infrastructure work.
